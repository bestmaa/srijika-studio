Srijika Studio is a **code-first React application studio**. Restricted, typed `.ui.tsx` is the only persisted UI source of truth. The hierarchy, Inspector, diagnostics, and React preview are derived views of that source.

:::caution[Public alpha]
The current milestone is a working code-first UI foundation. Rust-backed generated APIs and business logic are planned for Phase 2; they are not part of the current product.
:::

## The core promise

Visual tooling must never silently replace developer-owned code with a hidden format. Srijika permits an operation only when it can produce a bounded source edit, validate the expected content hash, compile the resulting TSX, and pass the same rules used everywhere else.

```text
.ui.tsx source
  → restricted non-executing compiler
  → diagnostics + stable source map + validated UiDocument
  → hierarchy + Inspector + React preview
  → bounded source edit intent
  → hash-checked save
  → compile again
```
