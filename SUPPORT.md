# Support

Use the repository's GitHub Discussions for setup questions, design conversations,
and general help. Use an issue when you can describe a reproducible defect or a
specific feature proposal.

Before posting:

1. Check the [documentation](docs/) and existing issues or discussions.
2. Include the Srijika version, operating system, Node.js/pnpm versions, and the
   smallest safe reproduction.
3. Remove credentials, personal information, private source code, and internal URLs
   from logs and screenshots.

Do not report an unpatched vulnerability publicly. Follow [SECURITY.md](SECURITY.md)
for private security reporting.
