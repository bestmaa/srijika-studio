# Community code of conduct

Srijika Studio is built in public by people with different backgrounds, experience
levels, and perspectives. Everyone participating in this project is expected to
help keep the community constructive, welcoming, and safe.

## Expected behavior

- Be respectful, patient, and specific.
- Discuss ideas and evidence without attacking people.
- Welcome questions and help contributors learn the project.
- Give actionable feedback and acknowledge tradeoffs.
- Respect privacy and do not publish another person's personal information.
- Accept maintainer decisions made to protect users, contributors, or the project.

## Unacceptable behavior

Harassment, threats, discrimination, sexualized attention, personal attacks,
deliberate disruption, doxxing, and repeated bad-faith participation are not
acceptable in project spaces.

## Enforcement

Maintainers may edit or remove content, lock conversations, reject contributions,
or temporarily or permanently restrict participation when behavior harms the
community. Enforcement decisions should be proportionate, documented privately
when appropriate, and protect the people reporting a concern.

Report public-content abuse with GitHub's reporting tools. For a sensitive report,
contact the repository owner privately through GitHub. Security vulnerabilities must
follow [SECURITY.md](SECURITY.md).

This code applies to repository issues, discussions, pull requests, reviews, release
channels, and other spaces where someone represents the Srijika Studio project.
